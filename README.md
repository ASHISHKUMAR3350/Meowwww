# Meowwww

Chrome-style AI agent extension with **text + voice** interaction.

## What this includes
- Extension popup UI like a mini assistant.
- You can type text and get a response.
- You can select response mode:
  - Text only
  - Voice only
  - Text + Voice
- Mic button for speech-to-text (browser dependent).

## Run as a Chrome extension
1. Open Chrome and go to `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this project folder (`Meowwww`) or the `extension/` folder.
5. Open the extension popup and start chatting.
